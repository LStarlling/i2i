# 快问快答题库

每题只有两个选项，都没有标准答案。提问时原样给出情境和选项，不要暗示倾向。本题库答完后，改为按档案最薄弱的地方现场出题，规则见 SKILL.md 的"五、快问快答"。

| 题号 | 情境 | A | B |
|---|---|---|---|
| Q01 | 周五下午，方案还差一处细节没打磨 | 先交出去，下周再迭代 | 留下来改完再交 |
| Q02 | 两份 offer：一份薪资高 20%，另一份做的事你更感兴趣 | 选薪资高的 | 选更感兴趣的 |
| Q03 | 领导的方向你不认同，但会上已经定了 | 私下找领导再争取一次 | 先按决定执行，用结果说话 |
| Q04 | 假期出行 | 提前规划好每天的行程 | 只订机票和酒店，到了再说 |
| Q05 | 同事请你帮个忙，但你手头很满 | 直接说明现在帮不了 | 先答应，挤时间做 |
| Q06 | 买一件用得上好几年的东西 | 花时间对比，买最合适的 | 买口碑最好的，省去研究时间 |
| Q07 | 新项目启动 | 先做出能跑的粗糙版本 | 先把架构和方案想清楚 |
| Q08 | 周末有空 | 约朋友出去 | 自己待着充电 |
| Q09 | 汇报材料 | 结论先行，细节放附录 | 按过程讲清来龙去脉 |
| Q10 | 发现同事的方案有明显问题 | 当面直接指出 | 私下委婉提醒 |
| Q11 | 一笔闲钱 | 稳健理财，保住本金 | 拿一部分博更高收益 |
| Q12 | 有个新工具可能提升效率，但要花时间学 | 马上试 | 等别人验证过再说 |
| Q13 | 晚饭 | 去吃过的、确定好吃的店 | 试一家没去过的 |
| Q14 | 任务目标不清晰 | 先问清楚再动手 | 先按理解做一版，拿去对齐 |
| Q15 | 两个需求只能先做一个 | 先做影响用户多的 | 先做实现成本低的 |
| Q16 | 朋友发来一个长期创业邀请 | 认真考虑 | 婉拒，保持现状 |
| Q17 | 写文档 | 越短越好，只写关键 | 写全，宁可多不可漏 |
| Q18 | 答应过的事临时有变 | 立即告知对方，重新约 | 尽量克服困难按原计划完成 |
| Q19 | 团队里有人效率明显偏低 | 直接和他本人谈 | 先向上反馈 |
| Q20 | 一个决定想了三天还定不下来 | 抛硬币，快速决定 | 继续收集信息 |
